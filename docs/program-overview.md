# AudioPlayer 程序说明

## 用途与边界

AudioPlayer 是基于 C# / WPF / .NET 10 的本地英语学习播放器。使用 NAudio 解码播放并按 PCM RMS/dBFS 能量检测静音，不使用语音识别、VAD 或云服务。音频中若有背景音乐或持续噪声，能量阈值未必等于实际语义停顿。

程序递归扫描所选文件夹及其子目录的 WAV、MP3、M4A，跳过设置中指定名称的子目录及其全部内容（默认不排除任何名称，精确匹配且不区分大小写，显式选择的根目录不受此规则限制），不跟随重解析点，不忽略其他目录扫描错误；按相对路径自然排序，读取专辑、时长（TagLibSharp），不读取未显示的标签标题。名称列显示不带扩展名的文件名；行提示仅显示父目录及读取错误，最大宽度为主窗口宽度减 48 DIP，自动换行、8 DIP 圆角。刷新或打开文件夹时先停止旧播放并清除文件列表、选择状态与旧文件夹路径；扫描成功后加载新文件，扫描失败则保持空列表和空路径并提示错误。正在写入的本程序裁剪临时音频不纳入扫描。双击行或聚焦行 Enter 播放，Space 播放/暂停，Stop 停止并归零，进度条 Seek，Left / Right 跳转相邻静音中点。Ctrl + Left / Right 按设置的后退/前进秒数定位（默认 5/4 秒），不依赖静音分析。Space 与上述方向键快捷键在主窗口内优先于焦点控件；设置对话框不拦截这些快捷键。

播放列表 `<实际 EXE 名>.playlist.json` 与 EXE 同目录，仅保存 `rootFolder` 和绝对路径数组 `files`，中文直接以 UTF-8 字符保存，兼容旧 Unicode 转义 JSON。启动时只读取并验证已保存路径，不自动播放或递归扫描；确认缺失的文件移除并保存，根目录确认不存在则清空；访问失败或损坏 JSON 保留旧文件并提示错误。恢复及裁剪输出插入同样使用配置的排除文件夹名称，恢复不跟随根目录下的重解析点；关闭窗口取消未完成的扫描并保留最后已保存列表。正常打开、刷新及当前目录树内裁剪输出插入后原子保存；目录扫描失败保存空状态，保存失败保留内存列表并提示。空目录仍保留根路径。

## 模块职责

| 类或文件 | 职责 |
| --- | --- |
| `MainWindow.xaml(.cs)` | WPF 交互、当前播放/选中项、分析与裁剪任务协调、关闭时等待任务 |
| `PlaybackEngine` | NAudio 播放设备和读取器、Play/Pause/Stop/Seek、同步停止与释放 |
| `AudioLibrary` / `AudioTrack` | 递归扫描、路径排序、标签与播放列表绑定 |
| `PlaylistStore` | EXE 同目录播放列表 JSON 读取及安全保存 |
| `SilenceDetector` / `SilenceRange` | 帧级 RMS/dBFS 静音检测及前后中点导航 |
| `SilenceResultStore` | 按文件保存结果、源元数据与区间验证、失败安全写入 |
| `SilenceTrimmer` / `FfmpegM4aTrimmer` | PCM 裁剪与 AAC/M4A FFmpeg stream copy，输出验证及安全提交 |
| `SilenceSettings` / `SettingsStore` / `SilenceSettingsWindow` | 参数校验、EXE 同目录配置保存与设置 UI |
| `ScriptContent` / `ScriptWindow` / `web/script.html` | 原文发现、校验、WebView2 渲染、时间同步与视觉行导航 |
| `ToastHost` | 主窗口和设置窗口中的 WPF 消息通知 |

这些具体模块直接协作，当前不需要 MVVM 框架、依赖注入或通用任务队列。播放器停止确认、后台检测取消、版本标记和安全关闭的异步保护属于必要逻辑，不应为缩短代码而去掉。

## 静音分析与导航

默认分析帧长 10 ms、最短停顿 300 ms、静音阈值 -45 dBFS、导航容差 200 ms、允许静音 2.0 s。前三项决定静音检测，第四项决定前后跳转的邻近排除范围，第五项只用于裁剪。完整输入范围和持久化行为见 [Configuration](Configuration.md)。

音频加载后先校验 `results/<完整音频文件名>.silent_segments.json`；有效直接读取区间，无效或不存在时后台扫描源 PCM。缓存以文件名、大小、UTC 修改时间、媒体时长/采样率/声道数、版本及前三项检测参数判断有效性；不计算 SHA。源文件在扫描或裁剪期间发生可检测的变化则中止旧结果的提交。缓存写入失败时本次会话仍可使用内存导航，但裁剪禁用。只修改导航容差或允许静音时长不触发 PCM 复扫。

## 长静音裁剪

选中列表项是裁剪源，不必等于当前播放项。只有该项的有效结果中存在长于允许时长的静音，且未处于互斥任务时剪刀按钮才启用。对静音区间 `[s,e)`，时长大于允许值 `T` 时，保留首尾各约 `T/2`，删除中间部分；按原始采样帧索引计算切点，避免多处删除造成时间轴偏移。

WAV/MP3 采用 PCM 流式跳过与最多 10 ms 的保留静音边缘淡化；AAC 编码的 M4A 通过用户可选安装的 FFmpeg `-c:a copy`，不重新编码、不应用 PCM 淡化。其他 M4A 编码不静默转码。运行时仅在需要 M4A 裁剪时检查 FFmpeg，详见 [FFmpeg 安装说明](FFmpeg-Setup.txt)。

临时音频完成验证、源文件未变化后，原子改名为 `<stem>.new.<ext>`；占名则依次尝试 `<stem>.new (1).<ext>` 等，源文件和既有输出永不覆盖。输出成功后单独分析新音频并写自己的 JSON；即使后续结果保存失败，也保留已提交的输出音频并提示。旧嵌套 `silence.json`、旧 `cache/` 不迁移也不自动删除。

## 界面与发行

设置窗口固定 480 × 430 DIP，音频设置页保留原五项参数、前后步长和排除文件夹；字幕参数页提供可选字体、字号、行高、段后间距、首行缩进及三组各五个无边框颜色球；选项卡使用主题色下划线、下拉框与音频输入框统一圆角、常规字重及行间距，不保留文字预览。两个页面共享恢复默认、取消与确定按钮。

主窗口初始宽高按工作区约 50% × 60% 居中计算，最小 520 × 420，允许调整与最大化。列表不显示行标题及行边框，保留虚拟化和交替行背景。工具栏 36×36 DIP 点击区域、28×28 图标，进度条控件高 36 DIP 并向下视觉偏移 10 DIP。Play/Pause 是一个按钮的两种状态，播放模式按钮位于刷新与原文按钮之间；原文按钮紧邻设置按钮左侧。

开发/发布命令见 [Testing](Testing.md) 和 [Publishing](Publishing.md)。历史测试数字与真实媒体的已验收/未验收范围均集中在 [Testing](Testing.md)，不在本说明重复。历史规格仍可从 [文档索引](README.md) 查看。

播放模式按单曲播放、单曲循环、顺序播放、列表循环依次切换；悬停提示仅显示当前模式名称。自然结束才自动续播；手动停止、定位到结尾、刷新、关闭和设备错误均不触发续播。复用当前播放器与操作串行化机制，切换到下一首时将对应行滚动至可见。模式保存在现有配置中。打开文件夹或设置模态对话框时暂缓自动续播；确认打开新目录取消旧续播，取消对话框后处理仍有效的自然结束。实际手动停止或定位优先于待处理的自动续播；无可播放内容或下一文件解码失败时停止并提示。

## 原文伴随窗口

原文按钮显示或隐藏独立的非模态 WPF 所有者窗口，默认宽 400 DIP、首次打开高度与主窗口相同，最小 200 × 300 DIP；独立调整大小，跟随主窗口右侧并按当前监视器工作区约束位置；关闭原文窗口仅隐藏，主窗口关闭时释放阅读器。混合 DPI 与多监视器行为待实机验证。

当前加载音频所在目录按文件名顺序查找首个顶层 JSON 对象 `filetype: "script"`，不按文件名匹配，不递归，不自动修正裁剪时间戳。用户保证对应关系。格式与 ReadArticles 一致：字符串 title（可空）、非空二维 paragraphs，每个句子包含 text 与 timed_units，每个时间单元为 [显示文本, 起始秒, 结束秒]，时间为两个 null 或有限非负且结束大于起始的数。原始句子文本优先，未对齐及无时间戳文字不着色。缺失或可识别但无效的原文显示提示，不中断音频；无法识别 filetype 的损坏 JSON 跳过。原文文件不写入。

WebView2 内嵌页面以实际播放器时间更新 SVG 裁剪着色；窗口可见且播放时约 25 ms 更新，否则恢复约 100 ms；只测量有效时间单元的实际换行位置，构建按文档顺序严格递增的时间—位置锚点，播放中在相邻锚点之间连续线性插值，并通过 requestAnimationFrame 逐帧跟随；音频采样间短时外推最多 50 ms，位置限制在自然滚动边界内。无每行固定停顿，时间戳不足或到达自然边界时不再移动；暂停冻结显示，显著跳转直接定位。滚轮以原位移的 25% 直接滚动，右侧原生滚动条拖动/点击使用同一时间—位置曲线反向插值定位，支持行内时间；自然上下边界选择首/末有效锚点，无有效锚点或未移动不触发定位。无时间戳文字不着色，但两锚点之间可连续插值定位。连续滚动预览更新主进度条，暂时暂停正在播放的音频，150 ms 无新事件后提交一次 Seek，恢复原播放状态；双击原文不定位。自动滚动不触发 Seek。主窗口使用单个待提交定位事务保存目标时间与原播放意图，提交与其他音频命令共用既有串行执行入口。异步命令结束后发送携带实际位置和新 epoch 的唯一 playback 快照；原文手动预览不覆盖音频时钟，过期请求/快照不生效，仅与已提交目标匹配的预览保留位置。主窗口命令优先，隐藏或阅读器故障取消待提交定位并恢复原播放意图，关闭应用不恢复。具体竞争边界及实际效果待实机验收。

字幕参数保存在现有配置，字号可选 17、18、19、20，默认字号 17、行高 1.6、首行缩进 2；仅本次移除的旧合法值在读取时内存归一化，确认保存后应用，不触发静音复扫。WebView2 不可用时只影响原文窗口。详见 [Configuration](Configuration.md) 和 [Testing](Testing.md)。

原文窗口保留调整尺寸与关闭，禁用最小化和最大化按钮。主窗口接收原生最小化命令时先关闭并释放原文窗口，再执行默认最小化；其他最小化路径通过状态变化补充关闭。恢复主窗口不自动打开原文，用户可点击原文按钮重新打开。
